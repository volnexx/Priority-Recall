# Архитектура исходников

Корневой `main.js` — только собранный файл, который загружает Obsidian. Изменения вносятся в `src/`, затем выполняется `npm run build`.

## Модули

- `settings.js` — настройки времени сна и их нормализация.
- `display.js` — форматирование текста и значков интерфейса.
- `parser.js` — разбор определений и перечней из Markdown.
- `scheduler.js` — интервалы, доступность карточек, выращивание и время повторений.
- `queue.js` — приоритеты и формирование очередей.
- `review-flow.js` — переходы между карточками после ответа.
- `file-state.js` — состояние файлов и сравнение результатов сканирования.
- `ui-shared.js` — общие константы и вспомогательные функции интерфейса.
- `queue-view.js` — правая панель очереди повторений.
- `review-view.js` — окно отдельной карточки повторения.
- `settings-tab.js` — вкладка настроек плагина.
- `plugin.js` — жизненный цикл плагина, хранение состояния, сканирование заметок и регистрация представлений.
- `main.js` — минимальная точка входа исходников.

## Сборка

`npm install`

`npm run build`

`npm run check`
